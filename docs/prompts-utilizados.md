Fase 1 — Definição do Projeto

Projeto: Detector de Golpes Digitais (Simulador Educacional)

1. Definição do Problema

Com o crescimento acelerado do uso da internet e de serviços digitais, aumentou significativamente a incidência de golpes virtuais. Ataques como phishing, mensagens fraudulentas via e-mail, SMS, WhatsApp e links maliciosos são frequentemente utilizados por criminosos para obter dados pessoais, credenciais de acesso e informações financeiras.

Grande parte desses ataques explora engenharia social, isto é, técnicas de manipulação psicológica que induzem a vítima a tomar decisões precipitadas ou confiar em mensagens aparentemente legítimas.

Um dos fatores que contribuem para o sucesso desses golpes é a falta de conhecimento dos usuários sobre segurança digital, especialmente entre iniciantes no uso da internet. Muitos usuários não conseguem identificar sinais típicos de fraude, como:

* Links suspeitos

* Erros de escrita

* Solicitações urgentes de informações pessoais

* Mensagens que simulam instituições conhecidas

Diante desse cenário, torna-se necessário desenvolver ferramentas educacionais interativas que auxiliem no aprendizado prático sobre como identificar e evitar golpes digitais.

2. Justificativa do Projeto

A segurança digital tornou-se uma competência essencial na sociedade contemporânea. Entretanto, grande parte dos programas de educação digital ainda apresenta conteúdos teóricos, que nem sempre conseguem preparar os usuários para situações reais encontradas no ambiente online.

O desenvolvimento de um simulador educacional de detecção de golpes digitais busca preencher essa lacuna ao oferecer uma experiência de aprendizado baseada em simulação prática. Ao interagir com exemplos de mensagens reais ou inspiradas em ataques reais, o usuário pode desenvolver habilidades críticas para reconhecer tentativas de fraude.

Além disso, a utilização de tecnologias modernas, como Inteligência Artificial generativa, possibilita a criação dinâmica de cenários variados de golpes digitais, aumentando a diversidade de exemplos apresentados ao usuário.

Dessa forma, o projeto contribui para a educação em segurança digital, promovendo maior conscientização e reduzindo a vulnerabilidade de usuários a fraudes online.

3. Objetivo Geral

Desenvolver uma aplicação educacional interativa capaz de simular mensagens digitais e treinar usuários na identificação de golpes virtuais, promovendo o aprendizado de boas práticas de segurança na internet.

4. Objetivos Específicos

* Criar um sistema capaz de apresentar diferentes tipos de mensagens digitais simuladas (e-mails, SMS, mensagens de aplicativos e notificações).

* Permitir que o usuário avalie cada mensagem e determine se ela representa um golpe ou uma comunicação legítima.

* Fornecer feedback educativo explicando os sinais que indicam fraude ou autenticidade na mensagem analisada.

* Utilizar Inteligência Artificial para auxiliar na geração ou análise de exemplos de mensagens fraudulentas.

* Desenvolver uma interface simples e intuitiva que facilite o uso por pessoas com diferentes níveis de * conhecimento digital.

* Promover a conscientização sobre práticas seguras no ambiente online.

5. Público-Alvo

O sistema será direcionado principalmente para:

* Usuários iniciantes da internet

* Estudantes em processo de alfabetização digital

* Pessoas com baixo conhecimento em segurança digital

* Idosos que utilizam aplicativos de comunicação

* Usuários interessados em aprender a identificar golpes digitais

Embora o foco esteja em usuários iniciantes, a aplicação também pode ser útil para qualquer pessoa que deseje aprimorar seus conhecimentos sobre segurança da informação no contexto cotidiano da internet.

6. Descrição da Solução Proposta

A solução proposta consiste no desenvolvimento de uma aplicação educacional interativa, estruturada como um simulador de identificação de golpes digitais.

O funcionamento da aplicação ocorrerá da seguinte forma:

6.1. O sistema apresentará ao usuário uma mensagem digital simulada, que poderá representar diferentes formatos, como:

* E-mail

* SMS

* Mensagem de aplicativos (ex.: WhatsApp)

* Notificação de serviço online

6.2. O usuário deverá analisar o conteúdo da mensagem e escolher entre duas opções:

* Golpe

* Mensagem legítima

6.3. Após a escolha do usuário, o sistema apresentará um feedback educativo, explicando:

* Se a resposta está correta ou incorreta

* Quais elementos da mensagem indicam tentativa de fraude ou legitimidade

O sistema poderá apresentar múltiplos cenários de simulação, permitindo que o usuário pratique diversas situações comuns de golpes digitais.

A aplicação poderá ser desenvolvida utilizando ferramentas No-Code ou Low-Code, integradas a serviços de Inteligência Artificial, permitindo rápida prototipagem e implementação do projeto.

7. Possíveis Impactos Sociais e Educacionais

O projeto possui potencial para gerar impactos positivos em diferentes aspectos:

* Impacto Educacional

Algumas possibilidades incluem:

Você é um desenvolvedor especialista em aplicações web educacionais utilizando JavaScript.

Estou desenvolvendo um projeto acadêmico chamado:

Detector de Golpes Digitais (Simulador Educacional)

O objetivo da aplicação é ensinar usuários iniciantes a identificar golpes digitais.

Eu já possuo um arquivo JSON contendo várias mensagens simuladas com a seguinte estrutura:

{

"explicacao": "A mensagem utiliza senso de urgência e direciona o usuário para um link suspeito que não pertence ao domínio oficial do banco.",
"nivel": "facil"
}

Preciso que você crie uma aplicação web simples que funcione como um simulador educativo.

Requisitos da aplicação:

1. Interface simples e clara para usuários iniciantes.
2. Exibir uma mensagem simulada por vez.
3. Mostrar os seguintes elementos da mensagem:

   * tipo da mensagem
   * título
   * remetente
   * conteúdo
   * link (se existir)
4. O usuário deve escolher entre dois botões:

   * "É golpe"
   * "É legítima"
5. Após a escolha, o sistema deve:

   * informar se o usuário acertou ou errou
   * mostrar a explicação educativa da mensagem
6. Deve existir um botão "Próxima mensagem".
7. As mensagens devem ser selecionadas aleatoriamente do arquivo JSON.
8. O sistema deve manter uma pontuação simples de acertos do usuário.

Peço que você gere:

1. O arquivo HTML da aplicação.
2. O arquivo CSS para estilização simples.
3. O arquivo JavaScript contendo a lógica do simulador.
4. Instruções de como organizar os arquivos do projeto.
5. Um exemplo de como carregar o arquivo JSON com as mensagens.

A aplicação deve funcionar apenas no navegador, sem necessidade de backend.

Escreva o código de forma clara e bem comentada, pois ele será utilizado em um projeto educacional.

## Resposta Recebida:

O prompt foi utilizado no GitHub Copilot para auxiliar na geração inicial da aplicação web do simulador educacional.

Como resultado, foram criados os principais arquivos do projeto:

* **index.html** — responsável pela estrutura da interface da aplicação exibida ao usuário.
* **styles.css** — arquivo de estilos que define a aparência visual da interface.
* **dataLoader.js** — módulo responsável por carregar os dados das mensagens a partir do arquivo de dataset utilizado pelo sistema.
* **app.js** — arquivo principal que inicializa a aplicação e integra os diferentes componentes do sistema.
* **simulator.js** — módulo que implementa a lógica do simulador, incluindo a exibição das mensagens, verificação da resposta do usuário e apresentação da explicação educativa.

Esses arquivos compõem a base funcional da aplicação “Detector de Golpes Digitais”, permitindo a execução do simulador no navegador e a interação do usuário com as mensagens simuladas.
